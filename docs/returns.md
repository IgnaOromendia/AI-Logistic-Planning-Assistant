# Política de devoluciones

Política ficticia para devoluciones solicitadas después de recibir un pedido. Si el destinatario rechaza el pedido en el domicilio, el transportista registra el rechazo como [entrega fallida](failed_deliveries.md). Los daños, errores de preparación y faltantes se tramitan como [reclamos](claims.md).

## Condiciones

- El destinatario puede solicitar una devolución por cambio de opinión dentro de los 15 días corridos posteriores a la entrega. El plazo comienza el día siguiente a la recepción.
- El producto debe estar sin uso y completo, con sus accesorios y con un embalaje que lo proteja durante el traslado. Los productos personalizados y los perecederos quedan excluidos de esta modalidad.
- La solicitud debe incluir el ID del pedido, los artículos y cantidades que se devuelven, y un medio de contacto. Se pueden devolver algunos artículos de un pedido.
- La primera recolección de una devolución autorizada es gratuita. Si falla por ausencia, Atención al Cliente ofrece un punto de entrega habilitado o informa el costo de otra visita antes de programarla.

## Autorización y recepción

1. Atención al Cliente confirma la elegibilidad dentro de un día hábil desde que recibe la solicitud completa. Si la aprueba, asigna un ID de devolución y envía las instrucciones de embalaje junto con las opciones de retiro o entrega en un punto habilitado.
2. El destinatario dispone de siete días corridos desde la autorización para entregar el paquete al transportista o en el punto habilitado. Si coordinó el retiro dentro de ese plazo y Operaciones debe reprogramarlo, la autorización se extiende hasta la nueva fecha. Quien recibe el paquete registra el ID de devolución y emite un comprobante.
3. Depósito registra la recepción e inspecciona los artículos dentro de dos días hábiles. Informa a Atención al Cliente la cantidad recibida y cualquier diferencia documentada.
4. Atención al Cliente confirma el resultado. Si la devolución se aprueba, Finanzas emite el reintegro de los artículos aceptados al medio de pago original dentro de cinco días hábiles desde la inspección. Si hay diferencias, Atención al Cliente explica el motivo y acuerda con el destinatario el retorno o la revisión de los artículos observados.

El caso se cierra cuando se registra la referencia del reintegro o se confirma la recepción de los artículos observados por el destinatario. El pedido original conserva su registro de entrega y cada devolución se vincula con su propio ID.
